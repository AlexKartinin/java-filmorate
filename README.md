# Filmorate

Бэкенд сервиса для работы с фильмами и оценками пользователей. Позволяет хранить информацию о фильмах и пользователях, выставлять лайки, добавлять друзей и получать топ рекомендованных фильмов.

## Технологии

- Java 21
- Spring Boot 3.5
- Lombok
- Maven

## Запуск

```bash
mvn spring-boot:run
```

Приложение запустится на `http://localhost:8080`.

## API

### Фильмы `/films`

| Метод | Эндпоинт | Описание | Коды ответа |
|-------|----------|----------|-------------|
| `GET` | `/films` | Получить список всех фильмов | `200` |
| `GET` | `/films/{id}` | Получить фильм по id | `200`, `404` |
| `POST` | `/films` | Добавить фильм | `200`, `400` |
| `PUT` | `/films` | Обновить фильм | `200`, `400`, `404` |
| `PUT` | `/films/{id}/like/{userId}` | Поставить лайк фильму | `200`, `404` |
| `DELETE` | `/films/{id}/like/{userId}` | Удалить лайк с фильма | `200`, `404` |
| `GET` | `/films/popular?count={count}` | Получить топ фильмов по лайкам (по умолчанию 10) | `200` |

**Поля фильма:**

| Поле | Тип | Ограничения |
|------|-----|-------------|
| `id` | `int` | Генерируется автоматически |
| `name` | `String` | Обязательное, не пустое |
| `description` | `String` | Максимум 200 символов |
| `releaseDate` | `LocalDate` | Не раньше 28.12.1895 |
| `duration` | `Integer` | Обязательное, положительное число |

### Пользователи `/users`

| Метод | Эндпоинт | Описание | Коды ответа |
|-------|----------|----------|-------------|
| `GET` | `/users` | Получить список всех пользователей | `200` |
| `GET` | `/users/{id}` | Получить пользователя по id | `200`, `404` |
| `POST` | `/users` | Создать пользователя | `200`, `400` |
| `PUT` | `/users` | Обновить пользователя | `200`, `400`, `404` |
| `PUT` | `/users/{id}/friends/{friendId}` | Добавить пользователя в друзья | `200`, `400`, `404` |
| `DELETE` | `/users/{id}/friends/{friendId}` | Удалить пользователя из друзей | `200`, `400`, `404` |
| `GET` | `/users/{id}/friends` | Получить список друзей | `200`, `404` |
| `GET` | `/users/{id}/friends/common/{otherId}` | Получить список общих друзей | `200`, `404` |

**Поля пользователя:**

| Поле | Тип | Ограничения |
|------|-----|-------------|
| `id` | `int` | Генерируется автоматически |
| `email` | `String` | Обязательное, должен содержать `@` |
| `login` | `String` | Обязательное, без пробелов |
| `name` | `String` | Если пустое — используется `login` |
| `birthday` | `LocalDate` | Не в будущем |
