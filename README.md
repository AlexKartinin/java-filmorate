# Filmorate

Бэкенд сервиса для работы с фильмами и оценками пользователей. Позволяет хранить информацию о фильмах и пользователях, а также возвращать топ фильмов, рекомендованных к просмотру.

## Технологии

- Java 21
- Spring Boot 3.5
- Lombok
- Maven

## Запуск

```bash
mvn spring-boot:run
```

Приложение запустится на `http://localhost:8080`.

## API

### Фильмы `/films`

| Метод | Эндпоинт | Описание | Коды ответа |
|-------|----------|----------|-------------|
| `GET` | `/films` | Получить список всех фильмов | `200` |
| `POST` | `/films` | Добавить фильм | `200`, `400` — ошибка валидации |
| `PUT` | `/films` | Обновить фильм | `200`, `400` — ошибка валидации, `404` — фильм не найден |

**Поля фильма:**

| Поле | Тип | Ограничения |
|------|-----|-------------|
| `id` | `int` | Генерируется автоматически |
| `name` | `String` | Обязательное, не пустое |
| `description` | `String` | Максимум 200 символов |
| `releaseDate` | `LocalDate` | Не раньше 28.12.1895 |
| `duration` | `Integer` | Обязательное, положительное число |

### Пользователи `/users`

| Метод | Эндпоинт | Описание | Коды ответа |
|-------|----------|----------|-------------|
| `GET` | `/users` | Получить список всех пользователей | `200` |
| `POST` | `/users` | Создать пользователя | `200`, `400` — ошибка валидации |
| `PUT` | `/users` | Обновить пользователя | `200`, `400` — ошибка валидации, `404` — пользователь не найден |

**Поля пользователя:**

| Поле | Тип | Ограничения |
|------|-----|-------------|
| `id` | `int` | Генерируется автоматически |
| `email` | `String` | Обязательное, должен содержать `@` |
| `login` | `String` | Обязательное, без пробелов |
| `name` | `String` | Если пустое — используется `login` |
| `birthday` | `LocalDate` | Не в будущем |
